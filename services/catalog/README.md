# Catalogue and retrieval service (M2)

Owner: Harsh Chaudhari. Authority: [common §§5, 10](../../docs/specs/02_COMMON_SPEC.md);
wire contract: [contracts/http/catalog.yaml](../../contracts/http/catalog.yaml), generated by
`python -m services.catalog.contract` (`--check` fails when stale).

```bash
CATALOG_DATABASE_URL=... INTERNAL_API_TOKEN=... uvicorn --factory services.catalog.app:create_app --port 8002
python -m services.catalog.worker --namespace bench-smoke   # stock consumer, its own Kafka group
python -m infra.catalog_relay                               # separate shared-outbox relay
```

`infra/compose.catalog.yaml` also starts these as `catalog`, `catalog-worker` and
`catalog-relay`. Add it to the PostgreSQL/streaming Compose files and explicitly
start all three after migrations. They must share the same private catalogue
database URL/schema; inside Compose use `postgres:5432`, not host loopback.
The relay uses the existing shared worker's 25-ms poll/100-row pass and one SQL
connection, with acknowledged shutdown before publisher close. It never publishes
inside an HTTP transaction. API pool 4 + stock worker 2 + relay 1 stays within the
ten-session service ceiling. Each process retains its 384-MiB/0.5-CPU cap; count
the whole group in a reviewed evaluation profile.

M4 verified real HTTP/SQL/Kafka on 8 November using an isolated synthetic catalogue,
then stopped the test processes. See [M4 evidence](../../docs/vichitr/progress.md).

Requests carry the headers in `RequestContext.headers()` (`X-Namespace`, `X-User-ID`, ...). Internal
routes need `Authorization: Bearer <INTERNAL_API_TOKEN>`. Mutations need `Idempotency-Key`.

Search applies every hard filter before ranking; an empty result is a valid answer and is never
relaxed. All five modes are implemented. `vector_exact`, `hybrid_exact` and `hybrid_ann` need the
locked model in `EMBEDDING_MODEL_DIR` and return 503 without it; `hybrid_ann` also needs the `r-ann`
index. Exact retrieval is the recommended mode at this catalogue size
([results](../../docs/harsh/experiments.md)).

| Setting | Default | Meaning |
|---|---|---|
| `CATALOG_MAX_CONNECTIONS` | 10 | Connection cap; the frozen evaluation profile uses 4 |
| `CATALOG_REUSE_CONNECTIONS` | `false` | The P1 experiment: keep idle sessions for the next request |
| `EMBEDDING_MODEL_DIR` | unset | Locked model files; vector modes are off without it |
| `QUOTE_TTL_SECONDS` | 60 | Quote lifetime |

Search and price changes write their events in the same transaction through Aditya's
`append_outbox`. Until that library exists these endpoints fail closed with 503 and `/health/ready`
is not ready; tests use an explicit double.

Stock events are absolute snapshots. A newer version replaces the row; stale and identical events
are no-ops; same ID or version with different content writes a local diagnostic; unknown SKUs wait
in `stock_deferred`. Offsets advance only after the projection transaction commits.
`GET /internal/v1/projection/receipts` exposes version and timing receipts for the freshness oracle.
