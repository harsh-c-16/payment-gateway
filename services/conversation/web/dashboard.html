How consistency is maintained

Explicit checkout confirmation and idempotency keys protect purchase requests. The order saga coordinates reservations and payments; compensation handles unsuccessful steps.

Local outboxes retain events for publication. Receipt identities, event IDs and versions support replay and duplicate suppression. Active manifests publish consistent analytical snapshots.

How to read this dashboard

Session charts cover this browser. Pipeline and order charts cover the displayed namespace and UTC day. Dataset sizes cover the entire active manifest. Receipt charts use a bounded sample.

Readiness probes are point-in-time observations. This demo runs on one Windows machine with Docker services. Failure Demo collects scoped stock and ledger audits. Live infrastructure observations are supplied by the local helper with explicit unavailable states.
